# 🧠 Project Synapse – Interactive Neural Web

Project Synapse is a real-time, kinematic, neural-network-inspired visualization built using **HTML5 Canvas** and **Vanilla JavaScript**.  
It simulates spatial physics, node interactions, repulsion forces, and dynamic connection rendering — all optimized for smooth 60 FPS animation.

---

## 🚀 Features

### 🔹 Real-Time Node Dynamics
- Randomized kinematic nodes  
- Velocity-based motion  
- Boundary collision & bounce physics  

### 🔹 Intelligent Connectivity
- Distance-based edge creation  
- Gradient-colored connection lines  
- Fade-out opacity based on distance  

### 🔹 Human Interaction Engine
- Mouse / Touch-based repulsion  
- Dynamic field force calculations  
- Smooth kinematic disruption on hover  

### 🔹 Customizable Control Panel
Includes interactive sliders for:
- Node Density  
- Connection Radius  
- Repulsion Field Strength  
- Kinetic Energy (speed multiplier)

Each parameter updates the system **live**.
